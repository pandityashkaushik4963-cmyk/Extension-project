# 🎭 JokeTime - Chrome Extension

A lightweight, clean, and engaging Google Chrome Extension that serves up hilarious, witty, and developer-friendly **Jokes of the Day** to brighten up your browsing sessions!

## 🚀 Features
* **Handpicked Humour:** Delivers high-quality tech, programming, and pop-culture jokes (like the legendary Chuck Norris paradoxes).
* **Minimalist UI:** Clean layout featuring smooth, rounded corners, crisp modern typography, and intuitive spacing.
* **Instant Refresh:** Tap the **"Another Joke!"** button to instantly cycle through fresh jokes without reloading.

## 🛠️ Tech Stack
* **Markup & Structure:** HTML5
* **Styling & Visuals:** CSS3 (Custom Dark Theme UI)
* **Logic & Functionality:** JavaScript (DOM manipulation and event handling)
* **Framework:** Chrome Extensions Manifest V3

## 📦 How to Install (Local Developer Setup)

To test and run this extension locally on your Google Chrome browser, follow these simple steps:

1. **Clone or Download** this repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Open Google Chrome and navigate to the extensions management page by entering `chrome://extensions/` in the URL bar.
3. Enable **Developer mode** by clicking the toggle switch in the top-right corner.
4. Click on the **"Load unpacked"** button located in the top-left corner.
5. Select the root folder of this project (the directory containing your `manifest.json` file).
6. 🎉 The extension is now successfully installed and pinned to your browser extension toolbar!
